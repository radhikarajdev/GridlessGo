# 🚗⚡ GridlessGo - AI-Powered Wireless EV Charging Roads

![GridlessGo Concept](https://via.placeholder.com/800x400?text=GridlessGo+Concept+Art)

**Revolutionizing urban mobility with dynamic wireless charging and AI-optimized routing**

## 🌟 Overview

GridlessGo transforms electric vehicle charging by turning roads into wireless power sources. Our system combines:
- **Embedded charging coils** in select roads
- **AI-driven route optimization** for efficient charging
- **Smart queue management** to minimize wait times
- **Adaptive learning** from user feedback

## 📂 Repository Contents

### 1. [Route Optimization & Queue Management](route_optimization.ipynb)
- Campus road network modeling (5x5 grid)
- Traffic-aware pathfinding using Dijkstra's algorithm
- Priority-based queue management (low battery first)
- Sliding window charging scheduling
- Visualization of optimized routes

### 2. [Improved Path Routing with User Feedback](Improved_path_routing_using_user_feedback.ipynb)
- City map modeling (10x10 grid)
- Disaster zone simulation
- Traditional Dijkstra's algorithm
- Q-learning with user feedback integration
- Comparative path visualization
